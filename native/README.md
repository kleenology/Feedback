# تطبيق الآيفون (Capacitor)

التطبيق يفتح نفس صفحة العميل `https://app.kleenology.me/app/`. أي تعديل يُدمج في الموقع يوصل لتطبيق المتجر مباشرة بدون رفع نسخة جديدة.
نرفع نسخة جديدة بس لو تغيّر شي في الغلاف نفسه (الأيقونة، الصلاحيات، الإضافات).

- معرّف التطبيق: `me.kleenology.app`
- الإضافات: الإشعارات، المشاركة، الاهتزاز، شريط الحالة، التطبيق
- الإشعارات: الخادم يرسلها مباشرة لآبل (`server/api/_lib/push.js`)، واللوحة تناديه بعد تغيير حالة الطلب

## البناء بدون ماك
GitHub → Actions → «تطبيق الآيفون» → Run workflow. يبني ويرفع على TestFlight.
يحتاج أسرار المستودع: `APPLE_TEAM_ID`, `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8` (راجع أول ملف `.github/workflows/ios.yml`).

## الإشعارات في Vercel
`APNS_KEY` (محتوى ملف ‎.p8‎ للإشعارات), `APNS_KEY_ID`, `APNS_TEAM_ID` — ومن غيرها الخادم يتجاهل الإرسال بهدوء.

## تعديل الغلاف
```
cd native && npm install && npx cap sync ios
```
